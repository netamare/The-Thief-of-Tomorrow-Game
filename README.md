# The Thief of Tomorrow

A futuristic stealth game about stealing impossible things from a city that can see what you’ll do next. Slip through the grid, read tomorrow’s security movements, loop the cameras, recover each artifact, and escape before the alarm catches up.

## Features

- Three handcrafted missions with increasingly challenging security layouts.
- Responsive keyboard driven stealth gameplay with guards, cameras, laser gates, and sealed exits.
- Tomorrow Vision reveals hidden paths and forecasts enemy positions. Chronal energy recharges while vision is off.
- Security terminals disable facility defenses. Recover each artifact and reach the exit to advance.
- Health, detection, score, energy, per mission high scores, and saved local records.
- Pause, restart, game over and victory screens, animated effects, and optional synthesized sound.
- Dark and light themes, mobile friendly vision control, help screen, and responsive layout.
- Built with React, TypeScript, Vite, CSS, Lucide icons, Web Audio, and local storage.

## Controls

| Input | Action |
| --- | --- |
| W A S D or arrow keys | Move |
| Space or Shift | Toggle Tomorrow Vision |
| P or Escape | Pause or resume |
| R | Restart current mission |
| H or ? | Open field notes |
| Enter | Begin the first mission |

## Setup

Install Node.js version 20 or newer. Run `npm install`, then `npm run dev`, and open the local URL printed by Vite. Create a production build with `npm run build`, or preview it with `npm run preview`.

## Technologies

React, TypeScript, Vite, CSS, Lucide React, Web Audio API, browser local storage.
